# Стикер в 1С

Браузерный конвертер сметного листа «Свод» в файл для 1С — построчный перенос VBA-макроса **«Стикер_1С»**.
Загружаете файл-донор (`.xlsx` / `.xlsm`), приложение обрабатывает его локально в браузере и отдаёт готовый
файл `ИмяДонора_1С.xlsx` (лист «Свод»).

## Что делает (как макрос)

1. Ищет лист **«Свод»**, читает **«Стикер»** из `J2`, проверяет наличие **«ГР»** в колонке `K`
   (если нет — спрашивает, продолжать ли — как `MsgBox` в макросе).
2. **Нумерация_1С** — иерархия `О → К → С → У → Э → Л1…Л4 → ГР → КЕР/ТМЦ`, номера вида `1.2.3.`;
   строки «КЕР» разбиваются на две (верхняя — золотая `#FFC000`, нижняя — жёлтая `#FFFF00`),
   «ТМЦ» получает жёлтую заливку, переносится количество `D = E`.
3. Удаляет служебные колонки (`H, I, J, M…R`), ставит заголовки `ИД 1С`, `Структура/Статья ССР` и т.д.
4. **Сквозные_формулы_1С** — `=ROUND(D*E;2)`, `=ROUND(D*F;2)` в колонках `K`/`L`,
   `SUMPRODUCT` по ценам и `SUM` по итогам, общий итог `=K+L`.
5. **Формат_1С** — колонка `G` красная (`#FF0000`), колонки `8–9` зелёные (`#92D050`) с серой тонкой
   границей, строки «ГР» — светло-синие, «Л3» — светло-зелёные (тематические цвета Excel),
   колонка `B` — формат `0_ ;-0 ` и выравнивание влево, колонка `G` — текстовый формат.
6. **Группировка_1С** — уровни структуры по числу точек в «ИД 1С» (сводка сверху, как `xlAbove`).
7. **Отчёт** — сверка: `Стикер` против итога `Σ СМР + Σ ТМЦ`, разница «Проверка».

Оформление донора (заливки, шрифты, границы, ширины колонок, объединения ячеек) переносится в готовый файл.

## Запуск локально

```bash
npm install
npm run dev        # разработка
npm run build      # сборка в dist/
```

## Размещение на GitHub Pages

Статическое приложение — достаточно собрать и опубликовать `dist/`:

```bash
npx vite build --base=./   # относительные пути, чтобы работало на github.io/репозиторий
```

Дальше — Settings → Pages → Branch: `gh-pages` (или любой каталог с собранными файлами),
либо экшен `actions/deploy-pages`.

## Логотипы

Приложение ищет логотипы в `public/`:

- `logo.png` — логотип файла-донора,
- `logo2.png` — логотип файла 1С.

Положите свои PNG с этими именами в `public/` — они подхватятся автоматически.
Пока PNG нет, используются штатные векторные `logo.svg` / `logo2.svg` (фолбэк встроен в код).

## Дизайн-система

Оформление — «чертёжный стол сметчика» (общая система с «КС‑6 · Мастер нового периода»):
бумага `#eef2ec` с миллиметровкой 26px, единственный зелёный акцент `#1e7145`,
бумажные карточки с жёсткой смещённой тенью, шрифты Unbounded / IBM Plex Sans / IBM Plex Mono,
каркас «мастер из 4 шагов + sticky-предпросмотр», тёмно-зелёный журнал обработки.

## Приватность

Файлы обрабатываются библиотекой [ExcelJS](https://github.com/exceljs/exceljs) целиком в браузере —
никакие данные никуда не отправляются.

## Стек

React + TypeScript + Vite + Tailwind CSS 4 · ExcelJS.
